### Blocking (fix before the release post)

1. `template-slot-replace-interprets-dollar-patterns` — **new class, found by the audit
   breaking itself.** `assembleReport` fills all six template slots with string-form
   `String.replace`, which interprets `$'` / `` $` `` / `$&` in the replacement. A shell
   regex anchor in one evidence block and a JSON-Schema pattern in one remediation spliced
   the document into itself, compounding on rebuild. Fix: function-form replace on all six
   slots + post-assembly assertion (one DOCTYPE, no `<!-- SLOT:`, `cased-data` parses) +
   a unit test with `$'`/`` $` ``/`$&` in the data. **Must rebuild the bundle** —
   `skills/cased/scripts/build-report.js:40775` is what users run.
2. `report-data-blob-script-breakout` — `JSON.stringify` into `<script id="cased-data">`
   unescaped; `</script>` in any audited source truncates the blob (viewer dead) and can
   execute in the reader's browser. Fix: `\uXXXX`-escape `<>&` U+2028/9; guard the parse
   in viewer.js (the `data` binding is dead anyway).
3. `eval-scorer-shells-out-model-authored-test-command` — `shell: true` on
   `recon.testing.command`, which the session under test can write. Fix: argv form, or
   only operator-authored sources.
