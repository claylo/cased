## 4. Root causes
1. No termination condition; open:0 trivially reachable; pass 7: "This is the seventh audit of this branch in twenty-four hours."
2. Non-deterministic scope; "clean" from N carries no info to N+1.
3. Auditor swapped mid-loop (Opus → Codex → reviewer-augmented), 1 vs 6 agents; finding count tracks agent count not code state.
4. Remediation per-slug not per-subsystem; pre-publish rules unknown to remediator.
5. No blast-radius sweep after a fix.
6. Pass-0 README never authored (scaffold committed); 43 findings incl 2 criticals remediated from findings.yaml alone, 0 pushback, ~6.6 min/fix.
Was release blocked? Genuinely twice (pass 0 two criticals; pass 1 exit-5 on GH-Actions YAML + silent comment loss). After pass 2, zero user-facing blockers; passes 3–7 = 80 perf/ownership/metadata/doc findings; pass 7 says "nothing blocks the publish." Passes 4–6 audit noise dressed as gating.

## 5. Recommendations
Audit: machine-readable `audit_profile:` in recon.yaml (surfaces, sensitivity floor, excluded tools, agent count, model) + scope-delta banner vs previous audit; freeze surface taxonomy (7 crustoleum + completeness); mandatory prior-audit reconciliation table (prior slug → still-fixed/regressed/superseded, verified vs fix diff); `caused_by:` field with introducing SHA (git log -S mostly mechanical; would flag 6/39 pass-7 findings); split reviewer into mechanical evidence-fidelity + adversarial validity, track rejection rate; gate on report completeness (no `<!-- AGENT:`); emit blockers.yaml vs backlog.yaml.
Remediation: `pre_publish: true` flag in AGENTS.md; blast-radius sweep per fix (grep co-varying text/docs/tests); regression test must measure claimed quantity (name metric); fix by subsystem not slug; batch ledger commit.
Termination: single pass with (1) zero critical/significant naming a user-visible failure mode, (2) reconciliation shows 0 regressed / 0 caused-by-previous-fix, (3) frozen surface profile, no tool exclusions beyond permanent waivers, (4) pass introduced no new fix commits — audits exact tree next tag ships. Two consecutive passes over an unchanged tree with empty blocker set is the signal.
